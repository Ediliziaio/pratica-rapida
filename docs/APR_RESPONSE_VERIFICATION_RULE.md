# APR — tripla verifica delle risposte

Ogni stato APR comunicato all'utente deve essere verificato tre volte con fonti e metodi differenti e indipendenti. In caso di discordanza lo stato è `non verificato`.

Le comunicazioni devono distinguere obbligatoriamente:

- collaudo automatico su fixture locali;
- test operativo collegato al CRM reale;
- test sul portale ENEA;
- disponibilità in produzione.

Il superamento di una categoria non autorizza a dichiarare pronta quella successiva.
